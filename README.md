# Global Skills (`medmrf-10/SKILLS`)

مستودع المهارات القياسية للوكلاء:

- **[`sheikh-curation`](./sheikh-curation/SKILL.md)**: منهجية فهرسة وتنقيح وتأريخ سلاسل المحاضرات والدروس الصوتية/المرئية للشيوخ والعلماء.
- **[`turath-deep-indexing`](./turath-deep-indexing/SKILL.md)**: منظومة الفهرسة العميقة والاستخراج الوكيلي المهيكل لكتب التراث الإسلامي عبر العلوم التسعة (التراجم، السيرة، التاريخ، التزكية، العقيدة، الفقه المالكي، أصول الفقه، علوم القرآن، القواعد الفقهية)، شاملةً قواعد الفحص الاستباقي (`Pre-Flight v4`)، بوابة الجودة الصارمة (`Gate v4/v4.1`)، سجل الأخطاء والدروس المستفادة عبر الجولات 1–10، وخارطة الطريق المفتوحة.

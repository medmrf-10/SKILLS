# Global Skills (`medmrf-10/SKILLS`)

مستودع المهارات القياسية للوكلاء:

- **[`sheikh-curation`](./sheikh-curation/SKILL.md)**: منهجية فهرسة وتنقيح وتأريخ سلاسل المحاضرات والدروس الصوتية/المرئية للشيوخ والعلماء.
- **[`turath-deep-indexing`](./turath-deep-indexing/SKILL.md)**: منظومة الفهرسة العميقة والاستخراج الوكيلي المهيكل لكتب التراث الإسلامي، قائمةً على قالبين إبستمولوجيين عامّين قابلين للتوسيع (القالب السردي/الخبري `Narrative Profile` · القالب التقعيدي/المعياري `Normative Profile`) وملفات تعريف علوم مسجّلة (`Registered Science Profiles`) يُضاف إليها أي علم جديد دون تعديل جوهر المهارة أو خوارزميات البوابة، مع الحفظ الحرفي التام للمتن (`100% Lossless Verbatim Partitioning`)، وقواعد الفحص الاستباقي (`Pre-Flight v4`)، وبوابة الجودة الصارمة (`Gate v4.2`)، والالتزام بأسماء المفاتيح المعيارية الصارمة. أما سجل الأخطاء والدروس فهو في `references/04`، وإحصاءات الجولات وحالة الكتب وخارطة الطريق في `references/05` (بيانات تحديثية لا معمارية).
- **[`sheikh-series-pipeline`](./sheikh-series-pipeline/SKILL.md)**: خطّ إنتاج سلاسل المشايخ من التسجيل إلى محاذاة تقارب ١٠٠٪ — التفريغ بـ`agy` (Gemini 3.8 Flash High) ولماذا لا `argon`، بوابة الجودة والتنظيف، والمحاذاة الزمنية لكل كلمة على الماك (MLX/whisper + DTW قسري)، وكتالوج الأخطاء وقواعد التشغيل على الخادم والماك.

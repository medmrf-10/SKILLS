# Global Skills (`medmrf-10/SKILLS`)

مستودع المهارات القياسية للوكلاء:

- **[`sheikh-curation`](./sheikh-curation/SKILL.md)**: منهجية فهرسة وتنقيح وتأريخ سلاسل المحاضرات والدروس الصوتية/المرئية للشيوخ والعلماء.
- **[`turath-deep-indexing`](./turath-deep-indexing/SKILL.md)**: منظومة الفهرسة العميقة والاستخراج الوكيلي المهيكل لكتب التراث الإسلامي، قائمةً على قالبين إبستمولوجيين عامّين قابلين للتوسيع (القالب السردي/الخبري `Narrative Profile` · القالب التقعيدي/المعياري `Normative Profile`) وملفات تعريف علوم مسجّلة (`Registered Science Profiles`) يُضاف إليها أي علم جديد دون تعديل جوهر المهارة أو خوارزميات البوابة، مع الحفظ الحرفي التام للمتن (`100% Lossless Verbatim Partitioning`)، وقواعد الفحص الاستباقي (`Pre-Flight v4`)، وبوابة الجودة الصارمة (`Gate v4.2`)، والالتزام بأسماء المفاتيح المعيارية الصارمة. أما سجل الأخطاء والدروس فهو في `references/04`، وإحصاءات الجولات وحالة الكتب وخارطة الطريق في `references/05` (بيانات تحديثية لا معمارية).
- **[`sheikh-series-pipeline`](./sheikh-series-pipeline/SKILL.md)**: خطّ إنتاج سلاسل المشايخ من التسجيل إلى محاذاة تقارب ١٠٠٪ — التفريغ بطبقة تبادلية عبر `agy` (الافتراضي Gemini 3.8 Flash High) ولماذا لا `argon`، بوابة الجودة والتنظيف، **والمحاذاة النقية v4 على الخادم وحده** (`extract_emissions` + `ctc_pure_align`، بلا Whisper وبلا كاش كلمات؛ وv3 التاريخية للمراسي للمتحقق المتقاطع)، داخل cgroup بسقف 2000M، وكتالوج الأخطاء وقواعد التشغيل. التفاصيل والتشغيل في `SKILL.md` والمراجع `01`–`10`.
- **[`turath-pdf-to-text`](./turath-pdf-to-text/SKILL.md)**: المحرك الموحد للتحويل البصري الحرفي لكتب الـ PDF العربية المصورة والطبعات الحجرية وحواشي الجداول الأزهرية/البولاقية إلى نص مهيكل بدقة ١٠٠٪ (`JSON` + `Markdown`) عبر رؤية `agy` (`Gemini 3.8 Flash`)، مع التنظيف الآمن لغبار المسح (`scipy.ndimage`)، ومصنّف التخطيطات الحتمي (شطر أفقي عند وادي الفراغ الأوسط بكثافة `2.4x`، وفصل عمودي للفهارس، وتدوير `90° CW` للمتون العمودية في الهامش)، وقفل `view_file` المتوازي الخافض للتوكنات `33.5x`، وبوابات الجودة الخمس، وحلقة التكبير البؤري المجهري المدمجة بدقة `2800px`.


أفكار تطوير المستودع نفسه (مقترحات مفتوحة، لا محتوى مهارة) في [DEV-IDEAS.md](./DEV-IDEAS.md).
